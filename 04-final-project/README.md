2. WHAT CAME BEFORE THE MEAT... ... ... THE BONES
Before I started writing any substance, I wanted to focus on making the bones of each level; basically defining each level as a function, then drawing a grid over the entire canvas, then drawing each string of text across the grids, then attaching them to the cipher code, THEN attaching the cipher code to mouseX. That part alone took 80% of my time coding, just making sure all the features of my sketch works. Then came mousePressed() to go the next scene. 

I ended up working like this: figure out caesar cipher to mouseX > format one function to be the template for all levels > write the story > copy paste yay!

I realised that planning my workflow was so important to ensuring that I'm not debugging as I'm writing, that all the fluff and pretty stuff can come after I get my features working sanely. Figuring this workflow out helped me lock into the process and made things less overwhelming.
